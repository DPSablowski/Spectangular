# ERFA (subset)

Part of ERFA (Essential Routines for Fundamental Astronomy) 2.0.1, https://github.com/liberfa/erfa,
derived with permission from the IAU SOFA library; licence in `LICENSE` (BSD 3-clause).
Only the 61 routines needed for the barycentric correction (`barycorr.cpp`) are included
(closure of `eraApco13`, `eraEpv00`, `eraDtdb`, `eraUtctai`, `eraTaitt`), unchanged.
